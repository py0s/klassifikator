# Классификатор объектов городской среды — Москва v9.0

## Архитектура

```
classifier-v9/
├── data/
│   ├── objects.json          ← ВСЕ объекты (ядра). Правь здесь, чтобы добавить/удалить/изменить объект
│   └── infrastructure.json   ← ВСЯ инфраструктура (слои). Правь здесь для инфраструктурных элементов
├── src/
│   ├── types.ts              ← TypeScript типы (структура данных)
│   ├── constants.ts          ← Орбиты, ядра, цвета, хелперы
│   ├── App.tsx               ← Корневой компонент (состояние, фильтры)
│   ├── main.tsx              ← Точка входа
│   ├── styles/
│   │   └── index.css         ← Все стили (CSS-переменные)
│   └── components/
│       ├── Header.tsx         ← Шапка
│       ├── StatsBar.tsx       ← Статистика (кол-во объектов, ядер, орбит)
│       ├── Filters.tsx        ← Фильтры по орбитам и ядрам
│       ├── CardGrid.tsx       ← Сетка карточек с разделением по орбитам
│       ├── ObjectCard.tsx     ← Карточка объекта (hover infra → подсветка)
│       ├── MatrixView.tsx     ← Матрица ядра×орбиты
│       ├── ObjectPopup.tsx    ← Попап объекта с панелью инфраструктуры
│       └── InfraDetailModal.tsx ← Детальное окно инфраструктурной секции
```

## Как работает связка «объект ↔ инфраструктура»

1. Каждый объект в `objects.json` имеет поле `infraCodes` — массив кодов инфраструктурных секций
2. Например, `"infraCodes": ["СВ.02", "ПК.02"]` означает, что объекту нужно освещение площадок (СВ.02) и безопасное покрытие (ПК.02)
3. На карточке объекта инфра-коды показываются как чипы внизу
4. **Наведение** на чип → подсвечиваются ВСЕ карточки с этим инфра-кодом
5. **Клик** на чип → открывается детальное окно секции с подвидами (СВ.02.01, СВ.02.02...)
6. **Клик** на карточку → попап объекта с панелью инфраструктуры внизу

## Как добавить новый объект

Открой `data/objects.json` и добавь:

```json
{
  "code": "О3.И.07",
  "icon": "🎯",
  "name": "Площадка для дартса",
  "key": false,
  "norm": "1 на 10 000 жит.",
  "area": "≥20 м²",
  "season": "Круглогод.",
  "desc": "Описание объекта...",
  "sats": [{"code": "ЗА.01", "name": "Туалет"}],
  "infraCodes": ["СВ.02", "ПК.01"]
}
```

Формат кода: `О{орбита}.{ядро}.{номер}` — например О3.И.07

## Как добавить новый инфраструктурный элемент

Открой `data/infrastructure.json`, найди нужный блок и секцию, добавь item:

```json
{"code": "СВ.01.06", "name": "Новый тип светильника", "specs": "Характеристики..."}
```

## Модель данных

### Объект (ClassifierObject)
| Поле | Тип | Описание |
|------|-----|----------|
| code | string | Уникальный код: О{орбита}.{ядро}.{номер} |
| icon | string | Эмодзи |
| name | string | Название |
| key | boolean | true = ключевое ядро |
| norm | string | Норматив размещения |
| area | string | Площадь или "—" |
| season | string | Сезонность |
| desc | string | Описание |
| sats | Satellite[] | Обязательные спутники |
| infraCodes | string[] | Коды инфраструктурных секций |

### Инфраструктура (InfraBlock → InfraSection → InfraItem)
- **Блок** (СВ, Ц, Н...): верхний уровень, 8 блоков
- **Секция** (СВ.01, СВ.02...): функциональная группа
- **Элемент** (СВ.01.01, СВ.01.02...): конкретный подвид с характеристиками

## Технологии

- **React 18** + TypeScript
- **Vite 5** — сборка
- **Данные** — JSON (без базы данных, правь файлы напрямую)
- **Стили** — чистый CSS с переменными
